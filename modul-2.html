2Claude masaüstü uygulamasının kurulması

Tarayıcı yerine bağımsız bir uygulama kullanmak istersen, Claude'un masaüstü uygulamasını bilgisayarına kurabilirsin. Bu, özellikle dosya sürükle-bırak ve bildirimler açısından daha rahat bir deneyim sunar.

1
claude.ai/download adresine git.

İşletim sistemine uygun (Windows/macOS) kurulum dosyası otomatik olarak önerilecektir.

2
İndirilen kurulum dosyasını çalıştır.

Windows'ta .exe dosyasına, macOS'ta .dmg dosyasına çift tıklayıp ekrandaki yönergeleri takip et.

3
Hesabınla giriş yap.

Bir önceki adımda oluşturduğun claude.ai hesabıyla oturum aç.

Windows, macOS ve Linux kurulum farklılıkları

  • Windows: Masaüstü uygulaması doğrudan .exe ile kurulur; terminal araçları için PowerShell veya Windows Terminal kullanılır. Claude Code gibi bazı araçlar için WSL (aşağıda anlatılıyor) önerilir.
  • macOS: Masaüstü uygulaması .dmg ile kurulur; yerleşik Terminal uygulaması doğrudan kullanılabilir, ekstra bir alt sisteme gerek yoktur.
  • Linux: Masaüstü uygulaması bazı dağıtımlarda paket yöneticisi (örn. apt, snap) ile veya doğrudan tarayıcı üzerinden claude.ai kullanılarak sağlanabilir; terminal zaten işletim sisteminin bir parçasıdır.

3Windows Subsystem for Linux (WSL) kurulumu

WSL, Windows içinde tam bir Linux ortamı çalıştırmanı sağlar. Claude Code gibi terminal tabanlı ajanlar Linux/macOS ortamında en sorunsuz şekilde çalışır; bu yüzden Windows kullanıyorsan WSL kurmanı öneririz (zorunlu değildir — doğrudan PowerShell üzerinden de devam edebilirsin).

# Windows PowerShell'i "Yönetici olarak çalıştır" ile açıp şu komutu yazın:
wsl --install

# Kurulum tamamlandıktan sonra bilgisayarı yeniden başlatın.
# Yeniden başlattıktan sonra bir Linux kullanıcı adı ve şifresi oluşturmanız istenecektir.

4Node.js ve gerekli geliştirme araçlarının kurulması

Node.js, Claude Code dâhil birçok modern yapay zekâ aracının çalışması için gereken temel çalışma ortamıdır. nodejs.org adresinden "LTS" (uzun süreli destek) etiketli sürümü indirmen yeterli.

# Kurulum tamamlandıktan sonra terminali (veya WSL'i) açıp doğrulayın:
node -v
# Örnek çıktı: v20.11.0

npm -v
# Örnek çıktı: 10.2.4

5Terminal ve komut satırı ortamının hazırlanması

Terminal, bilgisayarına fare yerine yazarak komut verdiğin pencredir. Windows'ta Windows Terminal veya PowerShell, macOS'ta yerleşik Terminal uygulaması, Linux'ta ise dağıtımın kendi terminali kullanılır. Bu programda terminal kullanımını Modül 3'te sıfırdan, çok daha ayrıntılı şekilde işleyeceğiz — burada sadece açık kalmasını sağlamamız yeterli.

6Claude Code kurulumu ve ilk komutun çalıştırılması

Node.js kurulduktan sonra, Claude Code'u terminale şu tek satırlık komutla kurabilirsin:

# 1. Adım: Claude Code'u global olarak kur
npm install -g @anthropic-ai/claude-code

# 2. Adım: Kurulumu doğrula
claude --version

# 3. Adım: Bir proje klasörüne geçip Claude Code'u başlat
cd Belgeler/ilk-projem
claude

# İlk çalıştırmada tarayıcı üzerinden Claude hesabınla giriş yapman istenecektir.
# Giriş yaptıktan sonra terminale doğrudan görev yazabilirsin, örneğin:
# > Bu klasörde basit bir "merhaba dünya" HTML sayfası oluştur.
✅
Başarı işareti

Terminalde claude yazdığında karşına Claude Code'un karşılama ekranı geliyorsa kurulum başarılı demektir.

7Visual Studio Code ile Claude Code kullanımı

Visual Studio Code (VS Code), en yaygın kullanılan ücretsiz kod editörüdür. Claude Code'u VS Code'un içine gömülü terminalden çalıştırarak, kod değişikliklerini editörde canlı olarak izleyebilirsin.

1
VS Code'u kur.

code.visualstudio.com adresinden işletim sistemine uygun sürümü indir.

2
Proje klasörünü aç.

VS Code'da "Dosya → Klasör Aç" ile üzerinde çalışacağın klasörü seç.

3
Gömülü terminali aç.

Üst menüden "Terminal → Yeni Terminal" seçeneğiyle VS Code içinde bir terminal penceresi açılır; buradan claude komutunu çalıştırabilirsin.

Terminal, masaüstü ve IDE üzerinden çalışma yöntemleri

Aynı Claude Code aracını üç farklı şekilde kullanabilirsin: doğrudan terminalden (hız ve kontrol için), masaüstü uygulaması içinden (daha görsel bir deneyim için) veya VS Code içine gömülü terminalden (kod değişikliklerini anlık izlemek için). Hangisini seçeceğin tamamen tercih meselesidir; bu program boyunca VS Code + terminal kombinasyonu önerilir.

8Model seçimi ve kullanım maliyetleri

Claude ailesinde farklı büyüklükte modeller bulunur: daha küçük/hızlı modeller basit görevler için düşük maliyetli ve hızlıyken, en güçlü modeller karmaşık muhakeme ve büyük kod tabanları için daha yüksek kaliteli ama daha maliyetli sonuç üretir. Genel kural: basit, tekrar eden bir görev için hızlı/ucuz modeli; karmaşık planlama veya büyük bir kod tabanının analizini gerektiren görevler için en güçlü modeli tercih et. Maliyet yönetimini Modül 10'da ayrıntılı olarak ele alacağız.
